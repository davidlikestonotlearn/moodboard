# Moodboard

A mobile-first React UI prototype. The bottom navigation switches between the moodboard and blank Home and Settings pages. Other buttons remain visual only. There is no backend, authentication, music service, or editing behavior.

## Run

Install Node.js LTS first, then run these commands from the project folder in PowerShell:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL printed in the terminal. Keep the terminal running while previewing; press Ctrl+C to stop it.

Create a production build with `npm.cmd run build`; serve it with `npm.cmd run preview`. Building generates `dist/`, which can be removed and regenerated. Use the local development URL to preview your edits rather than opening `index.html` directly.

## Project structure

- `src/`: React components, styles, and sample content. `App.jsx` manages the selected tab; `main.jsx` starts React.
- `public/`: Images and fonts used by the UI.
- `index.html`: Vite's HTML entry point.
- `package.json` and `package-lock.json`: Dependencies and run commands.
- `vite.config.js`: React JSX build configuration.
- `node_modules/`: Installed dependencies; generated by `npm.cmd install` and excluded from Git.

## Replace the sample content

Edit `src/data/sampleContent.js` and replace assets in `public/images`. Each board item declares its starting column/row and column/row span. The board always has two columns and four rows. The reusable image and playlist widgets also support the other requested spans, including 2×2.

The board uses square grid cells sized to both viewport dimensions. The header and navigation remain outside the grid, and safe-area insets are added to the shell padding. On desktop, the app stays centered at a maximum width of 440px.

See `public/images/CREDITS.md` for sample image sources.
